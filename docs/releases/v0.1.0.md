# ResearchRadar v0.1.0

ResearchRadar v0.1.0 is the first usable release of the local-first research brief pipeline.

It turns a reviewed research topic into a daily, evidence-checked WeChat draft: discover new papers,
select central sources, deep-read full papers, verify public claims against source anchors, and
create a draft in the WeChat Official Account editor for human review.

## Highlights

- Daily research brief pipeline from topic discovery to WeChat draft.
- Paper-first source selection with source history, centrality scoring, and public source curation.
- Tavily-backed web recall with canonicalization for arXiv, ACL, OpenReview, and GitHub sources.
- Full-paper acquisition for arXiv and OpenReview, with completeness checks to avoid abstract-only
  deep reads.
- DeepSeek v4 Pro reader route with structured full-paper reading, reader explanations, atomic
  claims, and source anchors.
- Codex `gpt-5.5` verifier route for conservative claim review.
- Evidence gates for publishable claims, including anchor completeness, claim linting, quote-only
  anchor repair, and table-aware evidence windows.
- Long-form Chinese and English report rendering, including WeChat-ready articles, references,
  figures, and readable paper explanations.
- WeChat draft-only publishing flow with image upload support and no automatic publishing or mass
  sending.
- Local launchd scheduler for daily WeChat draft generation.
- Optional provider routing for OpenAI-compatible providers, including DeepSeek and Xiaomi
  `mimo-v2.5-pro`.
- Provider listing, route inspection, and probe commands for safer model switching.
- Runtime summaries, model-call cache, failed-run diagnostics, privacy scan, and redacted audit
  artifacts.
- Public writing style contract for more natural reader explanations and localization without
  changing evidence or claim status.

## Quality Boundary

ResearchRadar is strict about public claims. Web snippets can improve discovery and ranking, but
reader-facing reports only use supported claims with complete source anchors. Weak, rejected,
unmatched, or unsupported claims stay in internal audit artifacts.

## Known Limitations

- Multi-topic recall and precision evaluation still needs to become a recurring quality gate.
- Topic bootstrap quality is not fully automated; new topic YAML should still be reviewed manually.
- Codex reader mode is not yet the default daily reader.
- Figure extraction is conservative. It prefers correct crops or source assets and omits uncertain
  figures rather than showing misleading page screenshots.
- First-run model latency can still be high; `--model-cache` is recommended for repeat smoke runs
  and debugging.
- WeChat is the validated publishing path. Future channels such as Zhihu should stay downstream of
  the verified article draft model.

## Upgrade Notes

This is the first tagged release. Existing local users should keep secrets in Keychain or a local
`.env`, keep `config.yaml` private, and run:

```bash
uv run research-radar privacy scan
uv run research-radar provider routes --config config.yaml --mode daily
uv run research-radar secrets status
```
